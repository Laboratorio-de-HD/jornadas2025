
# 📂 Datos de ejemplo

Esta carpeta contiene archivos de datos utilizados como ejemplos para acompañar las guías del sitio.

## 📄 Archivo disponible

- `plantilla_base_datos.csv`: una plantilla base con metadatos estructurados según el estándar Dublin Core. Puede usarse como punto de partida para crear bases de datos académicas o culturales.

## Uso

Puedes enlazar directamente este archivo en páginas o documentación de tu sitio con la siguiente ruta:

```
assets/data/plantilla_base_datos.csv
```

Este archivo está en formato `.csv` y es compatible con Google Colab, VS Code, y otros entornos de análisis de datos.
